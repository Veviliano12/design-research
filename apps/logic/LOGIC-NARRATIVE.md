# 研究逻辑 · 叙事与信息架构（2026-11-12，America/New_York）

研究逻辑是设计研究这本书里的第二章，夹在视效库和来源之间。页型仍是 presentation-pages 的能力论证：全屏暗色画布、一句目标、一张会动的总图。手法对齐同一套线稿密度、字体数字和单一强调色，不借用对方的品牌、口号或数字。

默认打开是一张会动的全页总图，不是虚线装饰，也不是四张断开的过程卡。页（示意页卡片，不假冒具体案例）像物件从左向右走：

`来源汇入` → `机器初筛` → `视效分类` → `人审` → `视效库`

机器初筛和人审是同一类工位：同样的圆角站框、同样的标题排版、同样的尺度、传送带脊线上同一只检查窗、同一种页物件。差别只在窗里的机制——初筛是规则闸门，人审是逐页看。未通过的从初筛工位向上（引擎，划掉）和向下（playground，划掉）离开，成为贴在该站框上的拒收托盘，仍用页物件，不编漏斗数字。人审通过的继续向右进入视效库；两条虚线回流从同一只检查窗离开：规则修订回到初筛，分类修订回到视效分类。回流标注贴在回路上、靠近对应模块，不漂在走廊里。

视效分类是一个模块：标题「03 视效分类」和「9 种」徽章在同一条模块头里，九行名称与条数同一宽度叠在头下，共同区域 + 接近，不再把「9」和列表拆到左右。动效不是分类轴，以划掉的芯片贴在该模块边框上。分类修订落在回路上，靠近本模块。

整页一起动，让人一眼跟上这一条：汇入 → 初筛 → 分类 → 人审 → 视效库。减少静态喊话。传送带上走的是页物件，不只是虚线。`点亮 / 排期` 收成视效库下的一行紧凑脚注（0 / 36 / 0，以及做了但不够的 27 页 / 94 页抽样），不单独占站，也不和下钻入口抢视线。事实仍在。

工位可点。点工位或点亮脚注时，在当前总图上打开同一套大弹窗，不跳到新页面，也不用 LayerSwitch 整页换走总图。平台 hash 仍是 `#/vfx/logic`，本场 hash 仍只记 `method`。Esc、关闭钮、点遮罩都关掉当前这一层，回到总图。顶栏与底栏仍在，读者知道自己还在研究逻辑这一章。若残留下钻状态，打开对应弹窗，而不是把总图换成整页详页。

标题仍是「设计研究」。色与字体与视效库共用：背景 `#0e0f11`，抬起面 `#17191c`，线 `#2a2d32`，正文 `#e8e9eb`，弱化 `#8b9098`，唯一强调色 `#3EC8FF`。

### 各站下钻（当前页上的大弹窗）

1. 01 汇入
   - 全名：页从三条主渠进入研究
   - 目的：讲清页从哪些渠道进入研究。先判断的是来源值不值得进来，不是某一页好不好看。
   - 方法：三条主渠及其下真实细渠道，页按条进入输入池。权威性是「值不值得进输入库」的五项加权初评（出品方 30%、维护与规模 25%、被引用 20%、文档与可核验 15%、许可与获取 10%）。每项 0–5，总分保留一位小数后再换成星级。有分时展示星级、总分、一句依据和五项分数；尚未打分如实写「尚未按准则打分」。不要和下一站的页面形态规则混成同一套。
2. 02 初筛
   - 全名：好看，且必须在完整页面或组件里
   - 目的：用规则做第一轮过滤，减轻人审，拦住明显不合格的输入。这不是权威评分。
   - 方法（已有，不是新发明，不另写第四条）：① 好看是门槛（不够好看的离开；现有例子：ThreeUI · Iridis「感觉不够好看？」、365 Tetrahedron「偏演示型线框几何，不够好看。」）；② 必须发生在完整页面或组件里（孤立物件照不过）；③ 引擎或 playground 的孤立场景照作为本站拒收托盘离开路径。线稿把「通过 / 被滤出」画清楚。正例只用已入库截图，并写明「通过的例子，不是自身对照」。不编造被滤出的条数。
3. 03 分类
   - 全名：按视效语言分类，不按动效
   - 目的：过了初筛的页按视效语言归入九类，供人审和视效库对照使用。动效不是一类，场景也不是主轴。
   - 方法：9 种真实类别，与数据一致，不发明第 10 种。动效不是分类轴。不要用场景当主轴：已入库 124 条里有 105 条是落地页，按场景分列会把空格夸大成结构窟窿。分类体系可被人审回流修订（新增 / 删减 / 合并 / 修改）。
4. 04 人审
   - 全名：同一来源也要逐页看，通过的进入视效库
   - 目的：人做最终判断；同一来源也要逐页看，不因来源已过权威性或初筛就整批放行。过的注入视效库，不过的变成反馈。
   - 方法：两条出口：注入视效库；反馈回流到初筛规则或分类体系。候审 30 不计入 124。构成可在详页给出：视效 119、视觉参考 5；整页 60、组件 64。
5. 视效库（总图节点，弹窗说明 124，不把节点本身当成跳章）
   - 目的：讲清已入库标杆是什么，并给出打开视效库章的安静链接。
   - 124 不是来源库全集，也不是自身已经做到的程度。弹窗不是 `#/vfx/overview` 本身。
6. 05 点亮 / 排期（库上的一层）
   - 全名：对照自身时分三层，再按杠杆排期
   - 目的：说明自身覆盖现状，以及有限时间里先补什么。
   - 方法：三层——点亮 0、做了但不够 36、接近标杆 0；不写「已掌握」。优先级：目标场景跑不起来的先不进名单；价值 = 区分度 × 复用面；难度只决定要不要提前投入。分版注入是规则，不编造「第一版 12 条」这类没有数据的批次数字。基础 / 高阶工作定义收在本下钻：① 是不是目标 H5 / Web 平台的默认能力；② 实现是否超出标准 CSS；③ 出现率只作校验；①② 都基础才是基础，有一条高阶即高阶。「把效果去掉，页面还能否成立」区分的是核心还是装饰，不用来判定高阶。场景可以加权，但不替换分类。对照无成对材料就写「待补充」。
