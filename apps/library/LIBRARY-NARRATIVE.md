# 视效库 · 叙事

库不是一份名单，也不是参考那面均匀铺开的案例橱窗。库是两层墙。第一层的单元是语言，第二层的单元是案例。两层都站在同一面凹进去的电影感展墙上：暗场、细边框、侧面强烈透视、左侧是压在墙上的目录字，不是实心侧栏。参考墙是手法的下限——我们可以用同一套空间语法，但必须把「类别」讲清楚，不能做成比它更糊的壁纸。

默认停在第一层。走进去还是墙，退回来还是墙。详情是盖在当前墙上的一层，不是新页面。

既有的分章导览舞台（`src/stage`，端口 5180）保持不动。本文件只讲视效库 map。

## 媒介

全屏 3D 舞台，镜头带着走，不是 WASD 展馆，也不是可滚的文档页。一层 WebGL 画布承载两层展墙和镜头；目录、页签、设备切换、底栏、场景片和详情是 DOM。页面本身不滚动，只有左侧目录在名单变长时内部滚动。

WebGL 无法创建时，两层逻辑仍在：先看到九张语言牌，点进一门语言再到该语言的平面陈列。不把整站卸成黑屏。缺图用中性底板加「暂无现场截图」，不用官方预览或任何替补图。

## 第一层：语言墙

打开即是这一层。墙上的单元是一种视效语言，不是一件案例。九块语言牌嵌在同一面凹圆柱墙上：上行五块、下行四块居中错缝，像墙面上的壁龛，不是 3×3 的产品卡片网格。牌与牌之间只留窄缝，背后是连续的墙面，侧面明显消退、有透视和明暗。第一次进来的人要在一秒钟内读出：「这是九种语言，贴在一面墙上」。九块都要同时可读，不靠旋转才能发现还有类别。

每一块牌必须一眼是类别，而不是缩小的案例墙：

- 排版清楚的语言名，长名在牌上可手动两行，不把词拆开。
- 由数据算出的件数，写成同一行的 `19 件`，不用手写数字，也不把数字和「件」上下叠成怪字。
- 一块从该语言真实缩略图里抽出的紧簇或扇面。件多的语言取若干代表，件少的语言有几张就几张。生成艺术只有 1 件、物理与软体只有 2 件，就只摆那 1 或 2 张，留出诚实的空，不准用别的语言的图来填。

左侧目录是压在墙上的字，带一层向右褪去的暗边，墙还在字后面。这里只列九种语言和件数，总数写「124 件」。当前或悬停的一行更亮，未选中稍暗。这一层不准出现 124 条案例名。点一块牌，或点目录里的一个语言名，进入第二层。

镜头可做极慢的闭合漂移。这一层也可以左右平移或拖动，但是有尽头：偏航夹得比较紧，到头有橡皮筋回弹，不会滑进全黑空白，也不会把左侧牌的标题推进目录字里。靠近目录的牌连同标题一起柔和消隐。默认偏航仍是 5+4 错缝的首屏构图，九块同时可读。键盘左右键在九种语言之间移动高亮，到头停住，不循环。

进入这一层时，目录上的 124 和每张牌上的件数从 0 滚动到真实值（约 1.8 秒，`power2.out`）。尊重 `prefers-reduced-motion`：直接给出终值，取消大位移。

## 第二层：语言里的案例墙

还是墙，不是文档网格，也不是另一个网站。手法对齐参考那面密的横向屏幕墙：细边框、三行密铺（件少时按件数收成一行或两行，不拿空框去凑三行）、两侧强烈透视。墙上只有这一门语言的案例。

进场要像把这块语言牌推开、走进去：镜头沿同一条路径前推（略朝向被点的那块牌再落回案例墙取景），其余八块牌退开并淡出，该语言的案例从牌的位置展开到案例墙上。时长约 1.8 秒，`power3.inOut`，镜头与姿态连续补间，不是硬切，也不淡到黑。半程时被点的那块牌还在，案例已经从牌上展开，其余牌只是变暗，目录仍停在语言层——读作走进那面墙，而不是先淡到黑再换场。目录等到案例墙已经站稳（blend 约 0.68）再换成该语言的名单。尊重减少动态：取消大位移，用约 0.45 秒的短淡入淡出把两层换上。退回是进场的反转，回到同一面九块语言牌；若离开前曾平移语言墙，退回时保留那一偏航，空间关系要认得出来。

### 场景是这一层的第二维

不同语言的场景构成不一样，这正是要被看见的事。左侧目录先给出返回「全部语言」，再以当前语言为标题，下面按场景分组列出案例。场景片是安静的切割：点一个场景，墙收到只剩含该场景的案例，并补间收拢，不另开一页。案例行和题名条上有短的场景标注。列表与墙保持同步。

分组规则：一件案例若除「落地页」外还有更特定的场景，归入官方顺序里第一个特定场景，以免 105 件落地页把少数场景吞掉；只有落地页的，仍归落地页。双标签的案例在筛选任一标签时都还在墙上。墙上为 0 的场景（内部工具）不出现空组。

件少的语言或被场景片切到只剩 1–3 件时，仍是同一面圆柱墙，不是黑底上飘着的一张产品卡。屏幕要更大、构图完整，落在目录右侧的开放舞台上，墙的弧度还在（墙面和轻微转角仍能看见）。不把 1–2 张图放大去铺成 32 件那种壁纸，也不借别的语言来凑密度。

点击、拖拽、滚轮和方向键转动案例墙。偏航夹在首尾列的取景之间，越出时有橡皮筋，松手回弹到最近一列；墙不是环，不会转进全黑空白，也不会从尽头绕到另一头。方向键走到首尾即停。点一件案例，在当前墙上打开详情浮层，墙的实例和镜头留在原地。Esc 先关详情；详情已关时，再按回到语言墙。「全部语言」同样退回第一层。

未选中的牌和案例更暗。当前选中的更亮，带一条霓虹蓝细描边；悬停只是略抬、略亮，不另画一圈同样的选中框。压在目录字后面的墙用透明度柔和收掉，像墙还在字后面继续，不留下一排黑框。右侧远沿同样收到暗场里，不要脏兮兮的残影。

## 设备与壳

顶部中央保留桌面 / 移动端切换，默认桌面。我们只有桌面实拍，不发明移动端截图。切到移动端时，墙上的屏幕撤空，只留下墙面本身，并在设备切换下方出一句极弱的说明「目前只有桌面现场」，避免被当成坏掉。不写「待补充」。

平台页签是「视效库」（当前）/「研究逻辑」/「来源」。底栏保留播放、重播、01–03 章节和字标「设计研究」。链回平台时，嵌入（`embed=1`）用 `target=_parent`。不搬「UCD Center」或参考的页签名。强调色只有霓虹蓝 `#3EC8FF`，背景 `#0e0f11`，抬起面 `#17191c`，线 `#2a2d32`，正文 `#e8e9eb`，弱化 `#8b9098`。不要引入第二条品牌色。

播放在语言墙缓慢轮换高亮的语言；在案例墙按列向前浏览。重播回到语言墙默认取景。
