# 设计资产来源库

业界设计资产与设计资源的来源清单：先作为后续设计输入的依据，再逐步沉淀成可共享的资源库。

本库负责「去哪里找、各是什么、值不值得进输入库」。权威性、它做的是什么、具体包含什么内容，是收不收的核心依据。深度分析可以在本库进行，也可以由其他人或 AI 从本库取用来源后，按自己的问题另做全景分析。

## 现在在哪

当前工作目录：`/workspace/design-resource-atlas`。项目仓库为私有 GitHub 仓库 [Veviliano12/design-resource-atlas](https://github.com/Veviliano12/design-resource-atlas)。Gary 的各位助手也可以直接读这个共享目录。不要并进 `visual-fx-atlas`：那份仓库是视效对标与评测产品，范围和本库不同。

可打勾审阅的界面是 `index.html`（用浏览器打开即可）。证据与打分以本目录的 Markdown 为准；HTML 是同一份概览的交互层。

## 两条工作线

1. **来源库线（本目录，由「设计资产来源」维护）**：按准则扩搜、核实官网与仓库、写概览、打权威分、跟踪可信度与分析状态。第一阶段优先收每个大渠道里最权威、最有影响力的来源，见 `phase-1-plan.md`。
2. **专项分析线（其他人或其他 AI）**：从本库取用来源，按自己的问题做梳理和全景地图。视效线的取用说明见 `handoff-vfx.md`。分析结论写回各自的交付物，不覆盖本库尚未核验的字段，也不代委托方标注可信度。

## 目录

| 文件 | 作用 |
| --- | --- |
| `research-criteria.md` | 已对齐的调研准则：四步流程、渠道与出品方、主类、五星打分、双状态、北极星问题、证据规则 |
| `phase-1-plan.md` | 第一阶段任务书：权威优先的纳入线、渠道任务与完成标准 |
| `execution-plan.md` | 当前执行计划：界面改版优先，来源库按批次核实并交付 |
| `handoff-vfx.md` | 给视效分析线的取用说明与当前相关来源 |
| `index.html` | 可筛选、可打勾的清单界面；勾选存在本机 `localStorage` |
| `authority-scores.md` | 打分工作表与依据 |
| `seed-inventory.md` | 起点名单的已核实事实 |
| `expansion-x.md` / `expansion-github.md` | 各渠道扩搜记录、未决名称 |
| `channel-tasks.md` | 较早的渠道扩搜计划（第一阶段优先级以 `phase-1-plan.md` 为准） |

`_reference-scene.html` 只是界面参考，不是清单数据，不作为对外交付。

## 使用约定

- 不编造网址、星标、价格、出品方、技术细节、洞察或结论。没有官方出处就不入库。
- 可信度由委托方标注；分析状态在深挖完成前保持「待分析」。
- 新增渠道或主类，先改 `research-criteria.md`，再写入清单。
